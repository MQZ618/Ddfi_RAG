# 面向城市洪涝灾后核查的低空 UAV 影像道路片段受淹情况判定（原始稿）

## 一、研究背景

城市洪涝灾后处置需要尽快掌握道路、建筑和公共设施受到影响的位置和基本情况。国家关于韧性城市建设和城市全域数字化转型的文件提出加强城市风险感知、应急联动和基础设施运行信息获取；北京市防汛应急预案将易积水道路及下凹式桥涵列为重点部位[1-3]。这些要求最终都要落实为能够定位、核查和更新的具体信息。

北京作为超大城市，道路网络密集，主干路、支路、立交桥区、下凹道路和公共服务设施周边道路相互连接。洪涝发生后，地面逐路核查能够取得直接信息，但积水扩展、局部区域难以进入和核查力量有限会压缩覆盖范围。低空 UAV 适合在重点片区快速获取高分辨率影像。北京在本文中只用于说明现实需求，不作为实验区域，也不依据公开数据实验推断北京地区的实际效果。

灾后低空影像能够同时呈现道路、水体、车辆、树木和建筑。语义分割可以把这些对象识别为像素类别，但独立类别不能直接说明具体道路片段受到何种影响。水体或受淹道路像素仍是判断道路受淹的主要信息，研究还需要利用道路宽度、方向、弯折和交叉口解释其分布，并处理周边对象重叠、道路遮挡和识别错误。最终结果应对应到道路片段，并指出哪些片段需要进一步确认。

## 二、现有研究及不足

洪涝制图研究主要输出淹没范围、易涝性或水深等栅格结果。现有综述表明，深度学习已经广泛用于洪涝范围和风险制图，实时应用、跨区域泛化和结果不确定性仍是持续问题[6]。低空影像研究能够提供更细的可见水体和灾后对象信息，但公开任务大多停留在场景分类或像素分割。

从任务层级看，现有研究大致包括洪涝范围提取、道路受淹或可通行性识别，以及灾后对象损伤判读。第一类回答哪里有水，第二类尝试回答道路是否受淹或能否通过，第三类面向建筑、道路及周边对象的灾后类别。三类工作都为本研究提供基础，但其输出通常是像素、影像块、网格或预先给定的道路标签，尚未把受淹区域相对于道路方向和宽度的分布作为主要研究对象。

FloodNet 在飓风 Harvey 后的 UAV 影像中分别标注 Road-flooded、Road-non-flooded、Water、车辆、树木和建筑等类别[4]。Road-flooded 已经包含道路受淹语义，Water 是独立类别；两类道路标签的并集只表示标注中可见且被归为道路的区域，不能恢复树冠、车辆或建筑遮挡下的完整道路范围。RescueNet 提供 Road-Clear、Road-Blocked、水体、车辆、树木和不同建筑损伤等级[5]。Road-Blocked 与 Road-flooded 不是同一含义，不能合并为同一状态。

已有工作开始把洪涝信息对应到道路。Ahmad 等利用卫星影像块判断道路是否可通行，其任务直接面向 passability，但标签、传感器和判断目标与本研究不同[7]。Sakamoto 将航空影像识别结果与道路和高程数据结合，在网格和道路段上表示受淹与未受淹区域[8]。这些工作证明道路段级表达可以实施，但没有直接研究受淹面积相近时，沿路连续、横向覆盖、局部集中和边缘分布是否对应不同的片段情况。

面向对象影像分析将相邻像素组织为可用于空间分析的对象，并使用形状、邻接和上下文信息[9]。这种思路为像素结果转向道路片段提供了基础，但道路片段不是普通连通区域。道路具有方向、宽度、弯折和交叉口，受淹区域相对于道路结构的位置需要单独计算和解释。

高分辨率光学影像只能直接记录传感器视角下可见的水体和道路。Tan 等指出，开放区域中的可见水体较易提取，阴影和树冠下的洪水难以从光学影像直接获得[10]。车辆、树木和建筑有时能够补充说明道路场景，有时只会遮挡道路主体或边界。仅凭类别掩膜重叠，不能认定车辆滞留、树木倒伏或道路实际被阻断。

道路片段级表达并不等同于把像素简单汇总到一个多边形。若只计算片段内受淹比例，同样比例可能来自沿路长距离延伸、局部横向覆盖或道路边缘的零散误分。前两种分布都可能对片段核查具有更直接的提示，边缘零散分布则更容易受到边界误差影响。现有相关工作为道路对象定位提供了方法依据，但这些分布之间的差异及其在不同道路结构下是否稳定，仍需专门验证。

因此，本研究不把重点放在增加一种分类器或若干特征，而是分析三组关系：受淹面积和分布与片段受淹情况的关系，道路结构对这些信息计算和解释的影响，以及复杂影像条件下何时可以给出结果、何时应转入复核。

## 三、研究对象与核心科学问题

本研究以灾后低空影像中的道路片段为基本分析单元。道路片段连接像素识别结果和道路核查位置，片段内整理可见道路范围、受淹道路或水体像素、道路局部结构，以及车辆、树木和建筑与道路的重叠和遮挡。片段可依据道路骨架、交叉口、弯折、宽度变化和适当长度窗口形成，具体划分在预实验中比较。

为使研究问题能够检验，片段受淹情况不由某一个预设阈值定义，而由统一判读规则和可复查样例形成参照。研究比较相同或相近受淹比例下不同分布的片段，也比较分布相近而道路宽度、弯折或交叉口条件不同的片段。若某项空间信息在这些比较中不能稳定区分片段情况，应据实说明其作用有限，而不是通过增加模型复杂度保留该变量。

上位科学问题：城市洪涝灾后，积水或受淹道路像素在道路片段内的面积和空间分布如何反映道路受淹情况，以及车辆、树木和建筑造成的重叠与遮挡，如何影响这种判断；当道路边界不清、识别结果零散或不同信息相互矛盾时，当前影像在什么条件下仍能支持可靠的片段判断？

子问题一：积水或受淹道路像素在片段内的面积、沿道路方向的连续分布、横向覆盖、局部集中和边缘位置，分别与道路片段受淹情况存在怎样的对应关系；道路宽度、方向、弯折和交叉口如何影响这些信息的计算和解释？

子问题二：当车辆、树木和建筑与道路区域重叠，或者道路边界不清、受淹区域识别零散、不同识别结果相互矛盾时，哪些信息仍能支持道路片段判断，哪些片段应转入复核？

两个子问题并非两条并列课题。子问题一确定受淹面积和分布能够提供什么信息，子问题二检查这些信息在遮挡、边界缺失和识别错误下还能否使用。前者提供主要判断依据，后者规定结果可以成立的场景范围，共同回答低空影像何时能够转化为道路片段核查信息。

研究允许部分变量在实验中作用有限，关注的是对应关系及其适用条件，不作因果解释。结论限定于灾后低空影像能够支持的道路受淹情况，不延伸到真实水深、道路实际通行能力、车辆滞留、树木倒伏或城市洪涝形成过程。

## 四、总体思路与道路片段信息组织

研究从原始影像及道路、水体和其他对象的识别结果出发。道路片段结合道路骨架、交叉口、弯折、可见宽度变化和适当长度窗口形成。道路被遮挡时，不补画无法确认的完整边界，而是在片段记录中区分可见道路部分和无法辨认的部分。

片段内的空间量在道路局部方向下表达。沿道路方向的连续分布反映受淹区域在片段长度上的延伸，横向覆盖反映其跨越可见道路宽度的情况，局部集中和边缘位置用于区分成片受淹与边界附近的零散区域。交叉口或明显弯折处不能直接沿用直线路段的计算方向，需要根据局部道路走向分段计算或作为单独场景分析。

受淹道路或水体像素是判断片段受淹情况的主要信息。每个片段记录受淹面积或比例，并在道路局部坐标中计算沿道路方向的连续分布、相对道路方向的横向覆盖、局部集中和边缘位置。道路宽度、方向、弯折和交叉口用于确定计算范围和解释分布，不发展为与水体并列的研究主线。

受淹比例的分母使用影像中能够辨认并被标注为道路的区域。道路被车辆、树冠或建筑遮挡的部分不补入分母，也不按未受淹处理。这样得到的是可见道路范围内的受淹信息，而不是完整道路断面的真实受淹比例。对于可见范围过小、关键横断位置不可见或道路边界无法确定的片段，记录具体原因并转入复核。

车辆、树木和建筑用于补充复杂场景。研究记录这些对象与可见道路区域是否邻近或重叠、是否遮挡道路主体或边界，以及影像中能否明确看出对象位于道路表面。能够明确辨认的占用可以作为补充信息；树冠覆盖、投影重叠、建筑邻接或只有类别掩膜交叠时，只记录道路被遮挡或边界难以辨认。

每个片段保留原始影像位置、道路和受淹掩膜、所用道路结构参照、其他对象重叠与遮挡情况，以及片段结果。该记录方式便于回到影像核查结论来源，也便于后续比较不同片段划分、分割模型或判读规则对结果的影响。片段之间的邻接关系只用于描述沿路连续变化，不据此推断未被影像覆盖区域的状态。

道路片段结果包括可见范围内的受淹面积和主要分布、道路结构参照、道路主体与边界是否清楚，以及是否需要进一步确认。开题阶段不固定最终类别和阈值。预实验可以比较互斥状态分类与分项记录两种组织方式，再选择更稳定、便于核查的方案。

## 五、研究内容与创新点

研究内容一：道路片段与多类影像信息整理。从道路识别结果中形成分析片段，记录道路方向、可见宽度、边界、弯折和交叉口；将受淹道路或水体像素对应到具体片段；记录车辆、树木和建筑与可见道路区域的邻近、重叠和遮挡，不恢复无法确认的遮挡下道路范围。

研究内容二：受淹区域分布与道路片段情况的关系。分析受淹面积、沿道路方向的连续分布、横向覆盖、局部集中和道路边缘零散分布。重点比较受淹比例相近而分布不同的片段，检查道路宽度、方向、弯折和交叉口是否改变这些信息的计算结果和解释。

研究内容三：其他对象和复杂影像条件对判断的影响。检查车辆、树木和建筑是否与道路重叠、是否遮挡道路主体或边界、影像中能否明确看出对象位于道路表面；同时检查分割结果是否零散、道路与受淹区域识别是否相互矛盾，据此区分能够给出结果的片段和需要复核的片段。

三项研究内容与两个科学问题直接对应。研究内容一提供道路片段和各类影像信息，是后续分析的共同基础；研究内容二回答第一个子问题，并验证创新点一；研究内容三回答第二个子问题，并验证创新点二。道路片段构建、类别选择和分类方法属于实现环节，不另列为创新。

创新点一：在道路片段内同时研究受淹面积和受淹区域的空间分布。研究沿道路方向的连续分布、横向覆盖、局部集中和边缘位置能否区分受淹面积相近但片段情况不同的道路，并分析道路结构对这些信息含义的影响。其核心不是增加若干手工特征，而是检验同样数量的受淹像素处于片段不同位置时是否具有不同的解释。

创新点二：在以受淹信息为主的前提下，研究车辆、树木和建筑对道路判断的两类作用：能够明确辨认时补充道路情况，遮挡或仅有掩膜重叠时说明影像信息不完整。对道路主体无法看清、边界难以确定、分割结果零散或不同信息相互矛盾的片段，转入复核流程。

两项创新都保留可被否定的空间。若受淹面积已经能够解释大部分片段差异，空间分布变量的增益可能有限；若车辆、树木和建筑信息不能稳定补充判断，其作用应收缩为遮挡记录。开题阶段提出的是明确、可验证的研究设想，最终结论由预实验和正式比较决定。

## 六、基本验证思路与后续研究安排

FloodNet 用于主要验证。Road-flooded 直接提供可见道路的受淹语义，Road-non-flooded 表示未受淹道路，Water 为独立类别。研究以两类道路标签覆盖的可见道路为基础形成片段，在道路主体和边界较清楚的样本中分析受淹面积与空间分布。该数据适合验证像素级受淹道路结果向片段信息的转化，但不能单独支持"独立水体如何造成道路受淹"的一般结论，也不能恢复遮挡下的完整道路。

RescueNet 用于补充复杂灾后场景。Road-Blocked 不与 FloodNet 的 Road-flooded 合并，车辆、树木和建筑标签也不作为具体阻断原因。该数据主要用于观察道路清通与阻断类别、周边对象重叠、道路遮挡和边界缺失，检查复杂场景记录方式能否稳定执行。

样本整理以原始影像和语义标签为依据。先筛选能够形成道路片段的影像，再按道路清晰程度、受淹范围、道路结构和周边对象情况建立片段记录。部分片段由多名标注者依据统一规则独立判读，通过一致性统计发现边界样例并集中复核。训练、验证和测试划分需要避免同一航带或高度相似的相邻影像同时进入不同集合，减少空间邻近造成的结果偏高。

验证按信息逐步增加的顺序组织：先使用受淹面积或比例，再加入沿道路方向的连续分布，随后加入横向覆盖、局部集中和边缘位置，最后加入道路宽度、方向、弯折和交叉口信息。比较重点是新增信息能否区分受淹比例相近的片段，以及这种作用是否随道路结构变化。

基础比较只使用受淹面积或比例，随后逐项增加沿路连续、横向覆盖、局部集中和边缘位置。道路结构信息既可以作为分组条件，也可以作为输入变量比较。这样可以区分两类结果：某项信息在各种道路条件下都提供稳定作用，或者只在特定宽度、弯折和交叉口场景中有效。具体采用规则、统计模型还是对象级分类器，由预实验中可解释性、稳定性和样本规模共同决定。

复杂场景分别考察道路清晰、分割零散、道路遮挡和信息矛盾的样本。比较对全部样本强制给出结果与先转出需复核片段两种处理方式，检查后者是否减少明显错误，并统计转入复核的片段数量和主要原因。评价内容可包括片段结果的一致性、不同错误类型和各类场景下的稳定性，具体指标随预实验确定。

复杂场景验证不以提高总体准确率为唯一目标。除总体结果外，还需要分别检查边缘零散误分、横向覆盖判断错误、道路被遮挡仍强制分类、Road-Blocked 与 Road-flooded 概念混用等错误。将片段转入复核后，应同时报告明显错误的变化和未自动给出结果的数量，避免只通过大量拒绝样本获得表面上更高的正确率。

后续先完成片段构建、判读规则和小规模预实验，再确定状态类别、变量组合、阈值及分类方法，随后开展正式比较和跨场景检查。DeepFlood 提供地理配准的航空与 SAR 影像并标注淹没植被，BlessemFlood21 提供高分辨率地理配准航空影像和水体掩膜[12-13]，可作为后续补充水体、植被遮挡和地理位置关联的候选数据；在实际取得并完成标签审查前，不把它们写成当前已有条件。

道路片段结果可以为后续的信息组织与任务安排提供结构化输入。近期的遥感与地理空间 Agent 研究已经开始评估多步规划、GIS 工具调用和灾害业务链，但现有系统在工具选择、参数定位和长流程稳定性方面仍有明显不足[14-16]。因此，Agent 适合保留为后续研究方向，定位为读取道路片段结果、汇总需复核位置、调用地图和影像工具、根据补充影像或现场核查更新记录并生成阶段性清单。只有当任务包含动态选择工具、接收反馈并更新下一步行动时，才有必要采用 Agent；固定的规则计算和一次性报告生成不需要用 Agent 包装。该内容在当前开题中控制为一段展望，不列入核心科学问题和创新点。
