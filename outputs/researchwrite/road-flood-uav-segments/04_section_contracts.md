# 04 Section Contracts — 每节契约

## 一、研究背景
- purpose：让"道路片段受淹判定"成为政策与核查任务的自然落点
- allowed：政策依据[1-3]；北京现实需求（含不作实验区的边界声明）；UAV 影像可行性；问题引入
- forbidden：文献综述展开；方法细节；数据集介绍
- inputs：政策文件、核查流程常识
- validation：读完应产生"需要道路级可核查信息"的结论，且无方法承诺

## 二、现有研究及不足
- purpose：分层综述 + 缺口收敛（分布相对道路结构未成为研究对象）
- allowed：四层文献（栅格制图/低空任务/道路级表达/OBIA+光学限制）；数据局限（FloodNet/RescueNet）；缺口句
- forbidden：超出引用的断言；把假设当事实
- inputs：[4]-[11]
- validation：每个缺口句都有上一条文献铺垫；[11] 在此节或验证节出现引用标记

## 三、研究对象与核心科学问题
- purpose：定义分析单元 + 参照标准 + 上位问题 + 子问题 + 关系 + 边界
- allowed：片段定义、判读规则参照、两子问题、关系说明、边界声明
- forbidden：研究内容（留给第五节）；具体指标/阈值
- inputs：第二节缺口
- validation：子问题一/二与第五节内容二/三可一一对应

## 四、总体思路与道路片段信息组织
- purpose：给出片段信息组织的**框架**（数据模型与计算规则）
- allowed：片段形成规则、局部坐标、受淹比例分母定义、遮挡记录规则、片段记录字段、结果组织方式
- forbidden：与第五节研究内容二重复列举分布特征的分析动作
- inputs：第三节
- validation：本节读完能复述"每个片段记录什么、怎么算、何时转复核"

## 五、研究内容与创新点
- purpose：三项研究内容 + 对应关系 + 两项创新 + 可否定空间
- allowed：内容一/二/三（动作层）、映射关系、创新点及否定条件
- forbidden：重新定义框架（指向第四节）；新增无证据承诺
- inputs：第三、四节
- validation：创新一/二都写明"什么证据会否定它"

## 六、基本验证思路与后续研究安排
- purpose：数据选择与局限、样本整理、增量比较、复杂场景、复核反作弊、后续安排与 Agent 展望
- allowed：[4][5] 主/辅验证及其局限；[12][13] 候选数据声明；[14-16] 展望；[11] 选择性分类引用点
- forbidden：把候选数据写成已有条件；把 Agent 写成核心内容
- inputs：第三、四、五节
- validation：验证步骤可覆盖两个子问题的全部变量；复核分流有反作弊约束
