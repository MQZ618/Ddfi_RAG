# 05 Style Guide — 术语、风格与禁用表达

## 术语台账（全稿统一）
| 规范形式 | 首次展开 | 禁用变体 |
|---|---|---|
| 道路片段 | 以道路骨架、交叉口、弯折、宽度变化和长度窗口划分的分析单元 | 道路段/路段（若指同一概念需统一） |
| 可见道路范围 | 影像中可辨认并被标注为道路的区域 | 道路范围（不加限定时易歧义） |
| 受淹比例 | 片段内受淹面积 ÷ 可见道路范围面积 | 受淹率（避免歧义） |
| 沿道路方向的连续分布 | 受淹区域在片段长度方向上的延伸特征 | 纵向分布（可保留为口语，正文统一前者） |
| 横向覆盖 | 受淹区域跨越可见道路宽度的情况 | 横向占比 |
| 局部集中 | 受淹区域在片段内成片集中的情况 | 聚集度 |
| 边缘位置/边缘零散分布 | 靠近道路边界的零散受淹像素 | 边缘分布（与边缘位置混用） |
| 道路结构 | 宽度、方向、弯折、交叉口的统称 | — |
| 复核 | 需进一步确认的片段分流 | 人工复核（首次可展开） |
| 判读规则 | 片段受淹情况的统一标注参照规则 | 判定规则（与算法判定混用） |
| Road-flooded / Road-non-flooded / Road-Blocked | 保留英文原文 | 中文意译（首现可括注） |
| UAV | 低空无人机（首现"低空 UAV（无人机）"） | 无人机（统一性） |

## 动词与承诺强度
- 禁止升级：不得把 "may indicate" 类表述改成 "proves"；"若…不能稳定区分…应据实说明"这类条件句保留
- 数据事实用 supported 动词；研究设想一律标注为待验证

## 禁用/限用表达（anti-slop）
- 禁用："具有重要意义"、"填补空白"、"提供理论基础"、"具有广阔应用前景"、"深入揭示"
- 限用（≤1 次）："为…提供基础"（原文 3 处 → 保留 1 处）
- 避免："本文拟"、机械的"首先/其次/再次/最后"、"在此基础上"
- 保留：必要的逻辑连接词（"因此"、"然而"），不因去模板化而丢失逻辑

## 结构纪律
- 一段一职责（context/gap/approach/result/comparison/mechanism/implication/limitation）
- 每节首段给出该节任务，末段收敛到下一节入口
- 引用编号维持 [1]-[16] 原体系，不重排；[11] 补正文引用；[13] 补著录信息
